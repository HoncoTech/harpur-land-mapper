Harpur Land Mapper

Version 7.9

Family land-mapping application for browsing saved plots on Google Satellite and adding/verifying parcels from Bihar BhuNaksha.

Navigation

Family PlotsSaved family land records on Google Maps, one survey context at a time.
Add Family PlotDynamic CS/RS survey-map workflow for adding or updating a family plot.
AboutApplication information and version.

Saved Plot workflow

  • All database plots with valid center coordinates appear as pins.
  • The selected plot BBox is drawn in red.
  • Optional Show plot shapes / boxes displays all saved BBoxes.
  • Select a plot from the master list to navigate directly to its pin.
  • Tap a pin to see plot number, owner, sheet, Directions and Details.
  • Directions opens Google Maps with the saved plot as destination; Google Maps can use the user's current location.

Important

This application is for family reference, visual matching and record keeping. Reconstructed parcel geometry and satellite alignment are not an official legal survey.

Google Maps Setup

A Google Maps JavaScript API key is required to display the maps.
