Harpur Land Mapper

Version 6.5

Family land database and cadastral mapping application for Harpur(199), Rajpur, Buxar, Bihar.

Version 6.5

  • Family Plots is now the default master-detail landing page.
  • Family Plots uses Google Maps only and does not depend on BhuNaksha PNG loading.
  • All saved plots with coordinates display as labeled pins.
  • The selected plot's saved BBox is drawn as a red rectangle.
  • An optional toggle can show all saved plot BBoxes.
  • Plot list selection navigates to the corresponding pin.
  • Pin annotation provides Directions and Details.
  • Directions opens Google Maps to the saved plot destination.
  • The prior cadastral workflow is now under Add Family Plot.
  • Mobile navigation uses a hamburger menu.
